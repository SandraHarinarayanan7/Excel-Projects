⭐ AI Companion Usage & Dependency Risk Analysis Dashboard

An Excel-based data analytics project exploring AI companion usage patterns and their relationships with social interaction, emotional well-being, sleep quality, and dependency risk. The project includes data cleaning, additional column creation, and interactive dashboard development to identify patterns across different user groups.
